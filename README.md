# Системы уравнений, кривые второго порядка и поиск текста

Актуальное условие: [main.pdf](main.pdf). Редактируемый исходник: [main.tex](main.tex).

Работа содержит три раздела:

1. Вычисление определителей, решение СЛАУ методом Крамера и определение координат вектора в новом базисе.
2. Приведение кривой второго порядка к каноническому виду. Раздел выполняется аналитически и не требует программной реализации. Графики строятся в графическом калькуляторе.
3. TF-IDF и поиск документов на английском языке.

Один номер варианта используется во всех подразделах приложения А.

## Начало работы

Python 3.10 или новее. Команды выполняются из папки лабораторной.

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если активация запрещена, вместо `python` можно использовать `.\.venv\Scripts\python.exe`.

## Файлы и проверки

- `solution.py`: 11 функций-заготовок. До их реализации при вызове функций возникает `NotImplementedError`.
- `run.py`, `tests/`: 9 групп, 18 тестов. Проверки запускаются последовательно по условию.
- `data/documents.json`: 24 английских документа по два предложения.
- `demo_text.py`: готовый скрипт поиска по корпусу из `data/documents.json`. Использует функции из `solution.py`; редактировать его не требуется.
- `examples/`: пример аналитического решения кривой и рисунок.
- [report_template.pdf](report_template.pdf): сокращённый пример оформления задачи 1.1 и раздела 2; [report_template.tex](report_template.tex) — его исходник. Пример не заменяет полный отчёт по всем заданиям. Рисунки для сборки находятся в `examples/report_figures/`.

```bash
python run.py --list
python run.py unittest determinant
python run.py --part algebra
python run.py --part text
python run.py
```

Для индивидуальных текстовых вариантов используются четыре документа из приложения к условию и `top_k=4`. Файл `variant_check.py` необходимо создать рядом с `solution.py` и поместить в него вызовы функций на своих данных.

После реализации текстовых функций выполнить итоговый поиск по готовому корпусу:

```bash
python demo_text.py "matrix vector"
python demo_text.py "neural network"
python demo_text.py "cat"
```

Для каждого запроса сохранить первые три результата: индексы документов, тексты и оценки косинусной близости. Кратко объяснить соответствие документов запросу. Документы с нулевыми оценками также могут входить в результат поиска.

## Сдача

Состав: `solution.py`, `variant_check.py`, `report.tex`, `report.pdf`, изображения из раздела 2. Подробные требования к выполнению и оформлению отчёта, формулы и варианты приведены в [условии](main.pdf). Файлы окружения и временные файлы сборки в сдачу не включаются.

Сборка условия: `xelatex main.tex` (два прохода) или `latexmk -xelatex main.tex`. Для данного исходника используются шрифты Times New Roman и Courier New. Для своего отчёта допускается другой установленный шрифт с кириллицей.

Сборка примера отчёта: `xelatex report_template.tex` (два прохода). Выполняйте сборку из корня репозитория, сохраняя папку `examples/` и её структуру.
